# ROI Drop Example

> Fictional example. Do not treat these values as real account data.

## Scenario

FlowNote 是一个 SaaS 产品，把粘贴的会议记录转成任务和截止日期。本周 ROI 从 `2.1` 降到 `1.4`，目标 ROI 是 `2.0`。

## Funnel

| Metric | Current | Baseline | Change |
| --- | ---: | ---: | ---: |
| Spend | $3,200 | $3,000 | +6.7% |
| Clicks | 6,100 | 6,300 | -3.2% |
| CPC | $0.52 | $0.48 | +8.3% |
| Registrations | 420 | 510 | -17.6% |
| Registration CPA | $7.62 | $5.88 | +29.6% |
| Trials | 112 | 164 | -31.7% |
| Trial CPA | $28.57 | $18.29 | +56.2% |
| Payments | 14 | 20 | -30.0% |
| Revenue | $4,480 | $6,300 | -28.9% |
| ROI | 1.40 | 2.10 | -33.3% |

## Diagnosis

主要问题不是单纯 CPC 上升，而是点击到注册和注册到试用两段同时下降，导致 trial CPA 恶化。付费样本下降使 ROI 低于目标，但 payment cohort 仍需继续成熟。

## Action

- 广告侧：降低低 trial-rate campaign 预算，拉 search-term anomaly review，隔离研究/免费意图词。
- 落地页侧：检查注册 CTA 和试用入口是否变更。
- 产品侧：检查 onboarding 是否新增摩擦。
- 业务决策：若高 ROI 目标继续压缩流量池，需确认是否保留学习预算。
