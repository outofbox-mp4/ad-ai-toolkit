# Visual Ad Creative Brief

## 适用场景

用于 Meta、TikTok、LinkedIn、YouTube、Display、Carousel、PMax asset group 等需要图片、视频或视觉表达的广告素材。纯 Search 标题/描述不适用，应使用 `search-ad-assets`。

## 输入数据要求

product truth、offer、目标动作、audience/persona、market、placement、brand rules、policy rules、landing page、历史表现数据、当前漏斗断点、approved claims、素材规格。

## 分析顺序

1. 先明确创意要解决哪个漏斗问题：CTR、点击到注册、注册到试用、试用到付费、AOV 或 ROI。
2. 提炼 audience tension / job to be done。
3. 将产品证据转成单一 proposition。
4. 设计 3-5 个可测试 angle，不做表层文案变体。
5. 每个 angle 写 hook、proof、visual direction、copy、CTA、placement adaptation、disallowed claims。
6. 定义测试变量、success metric、guardrails、学习窗口和下一步动作。

## 必须拆解的指标

CTR、CPC、click-to-registration rate、registration CPA、registration-to-trial rate、trial CPA、trial-to-payment rate、payment CPA、AOV、ROI。素材建议必须说明它主要影响哪一段。

## 必须分层的维度

audience/persona、market、placement、creative angle、format、funnel stage、landing page、offer、device。

## 判断阈值

- 只提升 CTR 但 trial/payment 弱的 angle 不建议扩量。
- 若 trial rate < 6% 且无 payment signal，创意 brief 应偏向资格筛选和高意图表达，而不是扩大泛流量。
- 没有 approved proof 的 claim 不得进入素材。
- 新素材测试未达到 10 个试用或 3 个付费前，不做最终 ROI 判定。

## 不允许跳过的证据

- 当前漏斗断点。
- 产品 proof 和 claim 来源。
- audience tension。
- 每个 angle 的测试变量。
- success metric、guardrails 和复盘窗口。

## 输出格式

1. Creative problem statement。
2. Audience tension and proposition。
3. Angle table：angle、hook、proof、visual direction、primary text、headline、CTA、placement adaptation、risk。
4. Production requirements。
5. Test plan：metric、threshold、guardrails、duration、next decision。
6. Action classification。

## 可执行动作分类

| Category | Allowed Output |
| --- | --- |
| 广告侧可执行 | 创意 brief、素材测试计划、placement adaptation、PMax asset group 建议 |
| 落地页/网站侧建议 | 页面信息层级、proof、CTA、素材到页面一致性 |
| 产品侧建议 | 需要补充的功能证据、案例、场景或定价表达 |
| 销售/运营侧建议 | demo/咨询型素材后的承接动作 |
| 需要业务决策 | 是否使用强承诺、竞品对比、价格/折扣、品牌风险角度 |

## Guardrails

- 不编造产品事实、折扣、客户、评价、结果或法律声明。
- 不利用敏感属性或脆弱人群进行 targeting/copy。
- regulated、comparative、performance claims 必须标注 legal/brand review。
