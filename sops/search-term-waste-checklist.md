# Search Term Waste Checklist

## When To Use

花费或 CPC 暴涨、CPA 异常、转化少或无转化，需要从搜索词排查异常原因时使用。

## Checklist

- 对比当前周期和基线周期的 query spend、clicks、CPC、registrations、trials、payments 和 ROI。
- 先找高花费 0 转化，再找高点击 0 注册、注册多 0 试用、试用多 0 付费。
- 标记新出现或突然放量的 query theme。
- 分类：无关、相关但错配、竞品、研究/教程、相关但低效、样本不足。
- 为否定词候选写明 match level、证据、误伤风险和审批人。
- 对相关但低效词，不要直接否定；先判断页面、offer、CPC 或下游承接问题。

## Output

输出必须包含高花费 0 转化队列、主题分类、根因假设、建议动作和需要验证的数据。
