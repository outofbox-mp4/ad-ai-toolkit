# Trial Drop Checklist

## When To Use

注册量看起来正常，但试用下降、注册到试用率下降，或试用 CPA 异常时使用。

## Checklist

- 对比注册、试用、注册到试用率、试用 CPA。
- 检查是否是某些 campaign、market、device、query theme 或 landing page 贡献了下降。
- 查注册来源是否从高意图变成低意图。
- 查试用入口是否变更：表单、验证、产品 onboarding、权限、价格展示。
- 查 trial conversion upload 或 CRM 同步是否延迟。
- 如果注册多但试用弱，不要把注册 CPA 便宜当作放量理由。

## Output

必须说明问题是广告流量质量、落地页/网站路径、产品激活，还是 tracking/upload 延迟。
