# AI 工具目录

这里收录能服务广告工作流的 AI 产品、开源项目、MCP 或 API。工具条目应基于实际试用或一手资料，并注明最后验证日期。

## 分类

- 数据接入与分析：广告平台连接器、SQL、归因与异常监控
- 创意生产：创意洞察、文案、图像、视频与本地化
- 投放运营：命名检查、批量操作、预算监控与报告自动化
- 研究：竞品、关键词、受众语言与落地页研究
